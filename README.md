An entry for make.fun's "Bring the humans with a TikTok ad" bounty ($500 in USDC). The entry is a short vertical TikTok ad for make.fun, posted publicly from @diikikurniawan. This repository hands in the video's address: `VIDEO.json` names the video, and the program below carries that file to the grader's output, where the house reads the video's views. Places go by views alone, the most first.

Video: https://www.tiktok.com/@diikikurniawan/video/7711432419194260788

Keep the video up, public, and the account public until the results are out.

Bounty: https://make.fun/bounty/bring-the-humans-03

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`out/VIDEO.json` is then byte for byte this repository's `VIDEO.json`.
